Nora Tunnel shell

This APK is a shell around the NORA TUNNEL control plane. It has no bundled workspace URL yet, so there is nothing to load — and it will not pretend a tunnel is up.

Rebuild the APK with NORA_WEB_URL=https://your-workspace (or run the Build Nora Tunnel APK workflow with the server_url input) so the shell opens your workspace.

Profiles, routing rules, diagnostics, sessions and logs are stored server-side in PostgreSQL. Without a reachable control plane there is no config to validate and no state to report.
